#  ASK AI Chat App - Flutter

A beautiful AI chat application built with Flutter featuring a sleek black and red design. This app provides a conversational interface to interact with an AI assistant.

## Features

- 🎨 Stunning black and red UI with modern design elements
- 💬 Real-time chat interface with animated bubbles
- 🤖 Mock AI service (easily replaceable with real API)
- 📱 Responsive design that works on mobile and tablet
- ⚡ Smooth animations and transitions
- 🔍 Message history tracking
